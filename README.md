# ATLAS детекторы — 1:100 интерактивті 3D симуляция

CERN ATLAS детекторының (1:100) 3MF моделіндегі **нақты бөлшектерден** (калориметрлер, тороид сақиналары, мюон камералары, дөңгелектер…) жиналған веб-сайт.

## Мүмкіндіктер
- **Жиналған көрініс** — қима режимімен (ішкі детектор, калориметр көрінеді).
- **Жару (exploded view)** — жүйелерді бір-бірінен бөліп көрсетеді (слайдер немесе «Жару / Жинау» батырмасы).
- **Рентген** режимі, жүйелерді қосу/өшіру, бөлікті басқанда сипаттамасы (қазақша).
- **Соқтығыс (pp) симуляциясы** — Хиггс→4μ, H→γγ, Z→ee, W→μν, джеттер, tt̄, «жаңа физика». Бөлшектер магнит өрісінде иіледі (соленоид 2 Тл, тороид ≈0,5 Тл), калориметрде энергия қалдырып тоқтайды, мюондар камераларда сигнал қалдырады, нейтрино → жетіспейтін энергия (MET).

## Іске қосу
```
cd site && python3 -m http.server 8000   # http://localhost:8000
```
Кез келген статикалық хостингке (GitHub Pages, Vercel…) `site/` қалтасын жүктеу жеткілікті.

## Модель қалай алынды
`ATLAS.3mf` — принтерге арналған 36 плитаның жиынтығы: бөлшектер жиналған күйде емес, баспа үстелінде жайылған. Сондықтан:
1. `tools/export_3mf.py` барлық бірегей торларды (100 дана) `site/models/parts.bin` + `parts.json` файлына шығарады (бөлшектердің өз геометриясы өзгеріссіз).
2. `site/js/layout.js` оларды ATLAS-тың нақты геометриясына сай (1 бірлік = 1 мм модель = 0,1 м детектор, шоқ = Z осі) орналастырады.

> Ескерту: 3MF-та жинау позициялары жоқ, сондықтан орналасу ATLAS құрылымы бойынша қайта құрылған — жеке бөлшектер нақты, ал олардың өзара позициясы (әсіресе тороид сақиналары мен үлкен дөңгелек камералары) жуықтап берілген.

```
python3 -I tools/export_3mf.py ATLAS.3mf site/models
```
